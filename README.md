# Chair in Mathematical Optimization

Static GitHub Pages website for the Chair in Mathematical Optimization at the University of Mannheim.

## Publish with GitHub Pages

1. Create a repository (for a personal site, use `<username>.github.io`; for a project site, any repository name works).
2. Push this folder to the repository’s `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The site has no build step or external dependencies. All CSS, JavaScript, photographs, and PDFs are stored in this repository.

## Updating content

- Edit the relevant page’s `index.html`.
- Shared navigation and footer content are in `assets/site.js`.
- Shared styling is in `assets/styles.css`.
- Add photographs to `assets/images/` and documents to `assets/docs/`.
